## Dedicated repository deployment instructions

Do not use the existing portfolio repository. Create a new **public** GitHub repository named `speak-thai-with-me` under the intended account or organization. Replace `<GITHUB-OWNER>` below with that account or organization name.

From the project directory in PowerShell:

```powershell
git init
git branch -M main
git add .
git commit -m "Prepare Speak Thai With Me for GitHub Pages"
git remote add origin https://github.com/<GITHUB-OWNER>/speak-thai-with-me.git
git push -u origin main
```

Then, in the new repository:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for the Pages workflow to finish and verify the published homepage, lessons JSON, navigation, and booking/contact state over HTTPS.

Expected project-site URL:

```text
https://<GITHUB-OWNER>.github.io/speak-thai-with-me/
```

If the repository is published by an organization, use that organization name in place of `<GITHUB-OWNER>`. This is an expected URL pattern, not a verified live address. Do not announce the site as live until GitHub Pages has deployed and the HTTPS URL has been checked.

Before accepting students, configure real teacher profile and contact/booking information in `js/config.js`, verify the configured address/provider, and complete the remaining native-speaker review.
